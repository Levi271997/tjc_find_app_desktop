# Commit rules

These apply to every commit, push and pull request in this repository.

1. **Author:** commit as `Levi271997 <levijanmartz27@gmail.com>` only (the repo's git config identity). Don't set any other author or committer.
2. **No Claude co-author:** never add a `Co-Authored-By: Claude ...` trailer, or any other co-author trailer, to a commit message.
3. **No Claude as contributor:** don't credit Claude anywhere that GitHub or git records contributors. That means no "Generated with Claude Code" lines in commit messages or PR descriptions, and no Claude author, committer or co-author identity.

These rules override any default attribution that Claude Code would otherwise add.
